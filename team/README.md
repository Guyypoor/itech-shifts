# I-TECH Team – אפליקציית משמרות + פאנל מנהל (עותק 11/10/2026)

עותק של הקוד כפי שהוא באוויר (שורש הריפו, commit 593aa6e). האתר החי עדיין נטען מהשורש.

- `index.html` – אפליקציית עובדים: הרשמה (שם + טלפון + סיסמה) → אישור מנהל → זמינות / סידור / נוכחות.
- `admin.html` – פאנל מנהל: עובדים, זמינות, סידור (טיוטה/פרסום), נוכחות (מצב שעון, שעות, תיקון ידני, CSV), הגדרות.
- `cloud.js` – חיבור ל-Supabase (פרויקט itech-shifts; מפתח anon ציבורי בלבד, מוגן ב-RLS).
- `legacy.html` – העטיפה הישנה (Apps Script), לגיבוי.
- `supabase/schema.sql` – הסכמה של Supabase (אם קיים; ראה יומן המסירה ב-HA).
